# 每日岛屿

原生 HTML / CSS / JavaScript 网站，使用 GitHub Pages 托管；具有灯塔 PWA 图标和基础离线缓存。

## 开发与部署

- `npm test`：任务、土地、历史手记、账户界面与同步冲突测试。
- `npm run build`：检查静态资源并复制 `dist/` 到 `build/`。
- GitHub Actions 在 `main` 更新后自动测试、构建和部署。
- 所有网站资源使用相对路径，适用于 `/daily-island/` 仓库路径。
- 主要入口 `dist/index.html`；任务规则 `dist/model.js`；岛屿绘制 `dist/scene.js`。

## 本地保存与账户

游客的所有功能保持可用，岛屿始终优先写入 `localStorage` 的 `daily-island-v1`。浏览器写入失败时仍显示原有保存警告。离线、登录失败或云端错误不会阻塞本地保存。

使用邮箱和密码注册/登录，昵称选填。密码不会写入存档；提交和关闭表单时清除输入。认证由 Supabase Auth 提供，SDK 将登录会话保存在独立的 `daily-island-auth-v1` 中并管理令牌刷新。退出仅退出当前浏览器的登录会话，保留本地岛屿。共用浏览器的人仍能看到本地记录，请使用各自的浏览器个人资料。

## Supabase 配置

1. 在对应项目 SQL Editor 运行一次 `supabase/init.sql`，创建 `daily_island_saves`、版本触发器和 RLS 权限。脚本遇到同名对象会停止，不覆盖已有表。
2. `dist/supabase-config.js` 配置 Project URL 和 **publishable key**。这些是浏览器公开配置，不能换成 secret/service_role key。
3. Authentication 中启用 Email；Site URL 和允许的 Redirect URLs 设为 `https://karenseven97.github.io/daily-island/`。
4. 当前项目启用了邮箱确认，用户需点击邮件再登录。给朋友开放注册前应配置自定义 SMTP；默认邮件服务限制收件人和频率。此应用不会自动关闭邮箱确认。
5. 如 Data API 被关闭或没有暴露 `public` schema，需要在 Supabase 中启用对应 API 访问。

账号由 Supabase Auth 管理，应用表只存 `user_id`、`snapshot`、`version` 和服务器更新时间。未登录角色没有应用表读写权限；登录用户的操作必须满足 `auth.uid() = user_id`。

## 同步与冲突

- 登录、恢复会话、保存修改、回到页面、网络恢复或点「立即同步」时检查/传输记录；不是实时协同编辑。保存后约 500 毫秒开始同步。
- 云端没有存档时上传当前本地存档。新设备的本地记录为空时自动采用云端存档；本地与云端都已有独立内容且无法判断来源时仍要求选择一次。
- 每次成功同步保存一份基础版本。下一次同时发现本地和云端变化时进行三方比较：单边变化自动采用；不同日期或不同任务的变化自动合并；土地坐标冲突会在保持连接的前提下重新安排。
- 同一任务被两边以不同方式修改、删除与修改同时发生、或出现两个不同的 S 级任务时暂停自动传输，由用户选择「使用云端记录」或「保留本地并上传」。更新请求仍同时过滤用户 ID 和预期版本，避免检查后的并发覆盖。
- 支持 Web Locks 的浏览器会让同一浏览器的多个标签页依次执行云端同步；本地记录变化继续通过浏览器存储事件传给其他标签页。没有 Web Locks 时仍由服务器版本号阻止静默覆盖。
- 使用云端版本后页面刷新。本地/云端被人工替换前会保存一份最近备份到 `daily-island-backup-v1`，账户窗口可下载。下一次切换会更新这份备份，重要版本请及时导出。
- 切换到另一个账户时不会自动上传原账户的本地记录。可以使用新账户已有的云端记录，或回到原账户。新账户没有云端记录时，可使用另一个浏览器个人资料开始。
- `daily-island-sync-v1` 保存所属用户 ID、上次服务器版本及三方合并所需的最近同步基础版本。网络、权限或建表错误显示「待传输」，不会假报成功。

## 检查范围

自动化覆盖游客、本地恢复、登录/退出界面、待确认邮箱、三方合并、真正冲突、并发保存、多标签页锁、账户切换、断网重试、备份失败和损坏存档。认证及云端行为使用隔离模拟对象；真实邮件送达及首次云端同步已经人工验证，跨设备并发仍需在真实设备上继续观察。

官方 Supabase SDK 固定版本本地托管，来源、完整性与许可证见 `THIRD_PARTY.md`。
