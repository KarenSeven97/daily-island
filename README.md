# 每日岛屿 · MVP

可直接托管的原生 HTML / CSS / JavaScript 网站，无构建依赖。项目包含 Web App Manifest、灯塔图标和基础离线缓存。

## 运行与检查

- 在普通本地开发环境中，可用任意静态文件服务器打开 `dist/`。
- `npm test`：检查任务规则、连通土地、持久化、跨日、历史补录与界面事件主流程。
- 主要入口为 `dist/index.html`，数据规则在 `dist/model.js`，统一主题和建筑绘制在 `dist/scene.js`。

## 第一版范围

每天恰好一个 S 才可开始；A/B/C/F 为可选任务。规划时不展示主题，开始时揭晓并锁定海风庭院。土地、起点小屋、S 灯塔、A 书屋及其余庭院景观使用同一主题定义。一个完成任务对应一块永久固定的邻接土地。完成 S 前角色停在起点；此后支持路径移动和轻度漫游。可以结算、跨日保存和补录历史已有任务。没有城市扩张、升级、商店、多 S、账号和云同步。

## 数据与验证限制

存档位于当前浏览器的 localStorage；刷新可恢复，更换浏览器或设备不会同步。历史补录默认明确保留“实际时间未知”，另存补录时间，也可确认具体时间。无法读取的存档不会被覆盖。

已在桌面浏览器确认 GitHub Pages 首页可以打开；未对手机触屏和断网状态进行真机验证。自动化覆盖数据规则及界面事件流程，不替代真机布局验证。

## 托管

GitHub Pages 通过 `.github/workflows/deploy.yml` 自动测试、构建并发布 `build/`。推送到 `main` 后会自动更新网站。项目资源和 PWA 作用范围使用相对路径，可部署在仓库子路径下。
